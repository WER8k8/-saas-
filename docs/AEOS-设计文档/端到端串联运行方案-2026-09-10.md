## 2. 三个断点（按修复顺序）

### 断点一：服务没起（阻塞一切）

- 官网 3000、admin 5174 **端口关闭**；后端疑似只绑 `127.0.0.1`，沙箱不可达。
- 8000 曾被 Apache/PHP(FunAdmin) 占用（你已改）。
- **修**：双击工作区根的 **`start-lan.bat`**（= `scripts\start-dev-lan.ps1 -ForceRestart`，绑 `0.0.0.0`）。起后后端 8001、admin 5173、官网 3000。

### 断点二：没有业务数据（阻塞验证）

- 229 张表里只有 11 张有数据；`inquiries`/`orders`/`products`/`content_masters` **全部 0 行**。
- 项目自带 `backend/seed.py` 就是造业务演示数据的（分类/商品/内容页/询盘/关键词 + admin 账号），但**从没在这个库上跑过**。
- **修**：见 §3 步骤 2。

### 断点三：两个入口缺失（阻塞完整闭环）

- **建站**：没有独立的 API 模块，能力散在 `site_ai_generator.py` / `public_tenant_*` 里，前端找不到稳定入口。
- **贸易订单**：`orders` 表在，但**没有对应的路由模块**（现有 `/orders` 是支付订单和许可订单，不是贸易订单）。
- **修**：这属于**开发任务**，不是配置问题——需要补 `routes/orders.py` 或把贸易订单并入 `cross_border.py`。

## 3. 串联 runbook（照着做）

### 步骤 0 · 起服务（你点一下）

双击 `start-lan.bat`。看到三个地址都打印出来即成功：

```
Backend : http://127.0.0.1:8001/docs
Login   : http://127.0.0.1:5173/login
Tenant  : http://127.0.0.1:3000/
```

### 步骤 1 · 我从沙箱验证服务真的通了

```bash
python3 tools/probe.py          # 端口 + HTTP + DB 一次查完
```

预期：8001 返回 FastAPI `/docs`、3000/5173 返回前端 HTML、5433 返回 PG 15.8。

### 步骤 2 · 灌业务种子（我来做）

优先跑项目自带的 `backend/seed.py`（需要后端环境）。若不便，我用 `psycopg2` 直连复刻它的关键插入：

- 分类 `categories`（4 类建材）
- 商品 `products`（带规格/图片）
- 内容页 `content_pages`
- 样例询盘 `inquiries`
- 关键词 `keywords`

**验收**：`python3 tools/db_probe.py --density` 显示这些表非空。

### 步骤 3 · 逐环走通（我从沙箱打接口）

| 环 | 验证动作 | 通过标准 |
|---|---|---|
| ① 登录 | `POST /api/v1/auth/login` 用 `admin/admin123` | 返回 token / 下发 Cookie |
| ② 租户 | `GET /api/v1/tenants` | 至少 1 条 |
| ④ 内容 | `POST /api/v1/content-master` 建一条 | 201 + 表里有行 |
| ⑤ 发布 | `POST /api/v1/unified-publish/quick-publish` | 生成 `publish_tasks` 记录 |
| ⑥ 询盘 | `POST /api/v1/inquiries/public`（免登录） | 201 + `inquiries` 有行 |
| ⑦ 报价 | `POST /api/v1/export-quote` | 生成报价单 |
| ⑧ 机会 | `POST /api/v1/opportunity` | 从 RFQ 建机会成功 |
| ⑩ 物流 | `GET /api/v1/logistics/track` | 返回轨迹结构 |

> 权限受限的端点用 `admin` 的 token；公开端点（`/inquiries/public`、`/rfq`）免登录。

### 步骤 4 · 补两个断点（开发任务）

- 建站入口：确认前端调用的是哪个路径 → 补一个 `routes/sites.py` 收敛，或明确文档化现有入口。
- 贸易订单：补 `routes/orders.py`（CRUD + 状态流转，复用 `models/enums.py` 的 `OrderStatus._TRANSITIONS`）。
