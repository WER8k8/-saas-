已落地效果 · 真实交互

下面的效果全部是纯 CSS、零依赖。可用右上的开关模拟「降低动态效果」偏好。

开启后所有动效应按无障碍要求静默

#8 弹性微缩触觉反馈

按下不只看透明度变化：瞬间压到 scale(.96) + 内阴影加深；松手时用带过冲的贝塞尔曲线微冲过头再回弹。

原理：用 cubic-bezier(.34,1.56,.64,1) 的 transition（y 值 > 1 天然过冲）， 不需要 JS 就能实现 Spring Overshoot。已显式排除 :disabled / .ant-btn-loading。

#7 物理弹簧交错流

每项带 45ms 时间差依次上滑弹入；第 13 项起 delay 截断到 540ms，长列表不会被拖慢。

共 8 项

#6 动态弥散光晕边框（安全子集）

旋转渐变描边保留；但原始描述里的「毛玻璃弥散光晕」在本项目不可用 —— backdrop-filter 因「送检水印穿透成文字重影」被全局禁用。 已改为 filter:blur() 的前景自模糊，不采样背板。

AI 能力模块

旋转渐变描边 + 呼吸弥散背光。适用于「AI 功能区 / 核心模块」，建议不超过 3 处。

仅描边（无背光）

不带 --glow 变体。长期动画占用合成层，铺开会影响帧率，故限 3 处。

降级：不支持 @property 的浏览器 → 退化为静态渐变环（@supports not (...)）； 降低透明度偏好 → 关闭背光；送检水印模式 → 描边停转、背光隐藏。
03

受限与不做的理由

❌ #2 流体胶囊形变 —— 建议不做

需要 FLIP / clip-path morph / 自定义 layout animation，项目零基建； Vue 生态没有成熟的「胶囊→面板」morph 库（framer-motion 是 React 的）； 且项目弹窗体系是 Ant 的 Modal/Drawer（13+ 处 a-drawer 在依赖现有行为）， 改造需覆写整条动画管线，会破坏弹窗一致性。

替代方案：给现有 Modal/Drawer 换高阻尼弹性缓动曲线 + 触发按钮加微缩反馈， 成本 几个 CSS 变量，保留约 80% 的连贯观感，零风险。

🟡 #1 3D 倾斜 —— 为什么受限

这是最关键的一条反向判断：本项目是 B2B 数据密集型后台， 主要交互对象是指标卡与表格。3D 倾斜会让数字产生透视形变，直接干扰读数 —— 与落地页/作品集场景完全不同。且需 mousemove 持续监听， 会与图表 tooltip、表格悬停高亮争抢；触屏上手指还会遮挡被按的面板。

落地条件：仅 @media (hover:hover) and (pointer:fine) 启用； 幅度 ≤ 4°；最多 3 处装饰卡；必须接 reduced-motion。
