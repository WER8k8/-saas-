2. 反模式裁决 & 执行摘要

反模式裁决：不读作"AI 一眼假"

主站（sb-page 系 + Tailwind 系首页/产品/联系）视觉语言**克制、统一、有工业工程感**：暖白底、单强调色建筑橙、2-4px 圆角、描边卡片、hover 仅加深阴影——未落入"紫蓝渐变 + 玻璃拟态 + 通用卡片 + 漂浮数字"的 AI 模板陷阱。反模式扣分全部来自**未清理的历史残留**（薄荷绿 fallback、蓝色移动组件、大圆角 CSS），而非当前设计取向。

执行摘要

  • P0×3 / P1×9 / P2×12 / P3×8，共 32 项；其中 P0 为 1 个品牌令牌硬违规（#2563eb）+ 2 个实测可复现的交互缺陷。
  • 最该先修的三件事：① request-quote.vue 蓝渐变（P0 令牌违规）；② 首页/报价锚点改用 useAppScroll（移动端实测失效）；③ 删除 mobile.css 暗色块（暗色系统下"亮底白字"对比失效）。
  • 既往 2026-09-07 清单核对：P0 两项已修、P1 四项已修三项；仍存移动端回到顶部缺失、部分圆角/焦点环残留（详见 §8）。

3. P0 阻塞项

P0Hero 蓝渐变硬编码 #2563eb — 撞 DESIGN-TOKEN-LOCKpages/request-quote.vue:353Theming / Anti-Pattern
蓝色渐变 Hero 与全站建筑橙工业风断裂，且是 AGENTS.md §3「禁止硬编码 #2563eb」的明文违规项（lint:tokens 应拦截）。
修复：改为墨色底 bg-[#17191c] 或暖白 bg-[#f5f4f0]（同 contact.vue 工业 Hero），删除线性蓝渐变。
违反：DESIGN-TOKEN-LOCK-01 / DESIGN.md 令牌单真源
P0首页 Product Finder 锚点跳转实测失效（window.scroll 与 #app 滚动容器不匹配）pages/index.vue:416-421Accessibility / Responsive
桌面实测点击"按应用领域选型 →"后 window.scrollY 与 #app.scrollTop 均为 0，页面纹丝不动；移动端（滚动容器 = #app）同样失效。用户在转化路径上无法跳转，等于三个选型入口全部死链。
修复：改用 useAppScroll（getAppScrollY/scrollAppToTop/onAppScroll，项目已封装），对 #app 滚动容器做动画跳转；锚点区已配 scroll-margin-top:88px 可保留。
违反：WCAG 2.4.4 链接目的；记忆规则「移动端滚动容器=#app」
P0联系页首屏被 fixed 顶栏遮挡（实测 top=-100px）pages/contact.vue:5（页面根无顶距）Accessibility / Responsive
浏览器实测首个可交互元素 getBoundingClientRect().top = -100px，页面 Hero（py-12=48px）被 56-80px 固定头盖住。桌面已可见遮挡，移动端更严重。
修复：页面根容器加 padding-top:56/64/80px（同 index.vue .flagship-home 三段式避让），或给首屏 Hero 补足顶距。
违反：WCAG 1.4.10 / 内容可用性

4. P1 严重项

P1报价页移动端滚动失效pages/quote.vue:327Accessibility / Responsive
直接 window.scrollTo，<768px 恒失效（滚动容器是 #app）。
修复：改 useAppScroll。
P1request-quote.vue 整页中文硬编码，12 语种 i18n 断裂pages/request-quote.vue（全页）Theming / i18n
该页零 $t()，多语言访客看到中文页面，破坏外贸官网核心价值（且该页是询盘转化页）。
修复：全部文案迁入 locales，复用 quote.* / contact.* 键。
P1mobile.css 暗色块全端生效，暗色系统下"亮底白字"对比失效assets/css/mobile.css:454-511Theming
@media(prefers-color-scheme:dark) 把 --color-surface/--color-text-primary 翻暗，但 main.css 的 body{background:#f5f4f0} 未覆盖——暗色系统用户看到暖白底 + 被翻白的文本变量，对比失效。main.css 已声明 color-scheme:light，此块与之直接矛盾。
修复：整块删除（主站锁定浅色工业风），或加 and (max-width:767px) 并同步覆盖 body 背景。
P1secondary 色板为完整蓝色系 — 令牌级品牌色冲突tailwind.config.ts（secondary 50-900）Theming
DESIGN.md 明确"secondary 仅限信息展示与链接，禁止作为品牌强调"，但 contact.vue:237 select 焦点环用 secondary-500（#3b82f6），实测联系页出现 64 个蓝色焦点环元素；蓝色系与"单强调色"哲学并存。
修复：删除 secondary 蓝色阶或全部改指向 primary 橙阶；contact.vue:237 焦点环改 focus:border-primary focus:ring-primary/20。
P1搜索框缺 label/name/autocomplete（三页同病）pages/products/index.vue:48-53 ｜ pages/cases/index.vue:46 ｜ pages/logistics/index.vue:24-53Accessibility
屏幕阅读器无字段名；自动填充失效；无 name 的表单提交语义残缺。
修复：加 <label for>/aria-label + name="q" + autocomplete="off"（搜索语义）；logistics 的 label 补 for、input 补 id。
违反：WCAG 1.3.1 / 3.3.2
P1StickyImBar 品牌色违规 + 表单无障碍 + alert()components/StickyImBar.vue:207-209, 85, 54-81, 276Theming / Accessibility
移动端吸底条（真实可见）：WhatsApp 主按钮 bg-emerald-700（薄荷绿）、Telegram bg-blue-500（蓝）、提交按钮 rounded-xl（12px 大圆角）、表单 4 个 input 全无 label、提交/失败用 alert()。
修复：主按钮统一 bg-[#17191c]（同 header-quote-btn）或建筑橙；表单加 aria-label/placeholder 组合；alert 改页内 role="status" 提示；圆角 4px。
违反：DESIGN-TOKEN-LOCK / WCAG 1.3.1 / 4.1.2
P1products/index.vue 数据拉取失败显示误导空态pages/products/index.vue:320UX
dataError 解构后未渲染，接口失败时用户看到"空列表"而非错误说明，误判为无货。
修复：失败渲染 EmptyState + 重试按钮。
P1分类筛选/翻页按钮触控不足pages/products/index.vue:36（≈28px）｜ certifications（certs-filter 34px）｜ cases/index.vue:32（36px）Accessibility
低于 44px 触控最小目标，拇指误触/难触。
修复：min-h-[44px]（或 40px+8px 间距）。
违反：WCAG 2.5.5（AAA）/ 2.5.8 间距
P1卡片 hover translateY 跳动违反设计契约components/ResponsiveCard.vue:5Anti-Pattern
site-tokens 明确"卡片 hover 仅加深阴影，禁止 translateY 跳动"，此处 hover:-translate-y-1 默认开启。
