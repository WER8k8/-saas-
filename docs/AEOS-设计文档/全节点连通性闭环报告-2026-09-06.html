2. 已修复的断点（本轮）

断点根因修复动作

RBAC 种子数据全为空 admin_roles/permissions/menus 的 id 在 PG 下是 UUID， 而 app/db/seed.py 写入 "role-super-admin-001" 这类字符串 → InvalidTextRepresentation；异常被 app/main.py:96 except Exception: pass 静默吞掉 新增 _sid()（uuid5 稳定映射）+ _uid() 改为返回标准 UUID； 5 处 ID 写入点全部归一；原文件备份为 app/db/seed.py.bak-20260906
用户与角色未关联 users.role_id 全部为 NULL，权限链断裂 按 users.role = admin_roles.name 回填，admin → super_admin 已绑定
误判"业务路由全丢" 统计方式只数 APIRoute，而 FastAPI 0.139.2 把 include_router 的子路由 包装为 _IncludedRouter（真实字段是 original_router） 重写递归统计脚本，实测 1323 端点，结论更正
