# 优丁全项目 · 细胞级细节总谱（获客莫比乌斯北极星）

> **什么叫「细胞级」**：每个实体字段、每个状态转移、每个节点入参出参、每条业务规则、每个界面槽位、每项指标公式——能直接开发，不再靠「大概」  
> **北极星**：获客全链路丝滑 + 外贸获客莫比乌斯 + 商业正循环（体验→付费→经验→更准）  
> **业务书**：第二大脑 18 · 细部 08 §9–17 · 架构：外层 DSH / 内层爱马仕  
> **日期**：2026-09-14

# 第 0 篇 · 细胞分类法（全项目统一）

| 细胞类型 | 含义 | 存放 |
|----------|------|------|
| **E** 实体细胞 | 表/模型 + 字段 + 枚举 + 索引 | models / schema |
| **S** 状态机细胞 | 状态集 + 转移 + 守卫 + 副作用 | services / supervisor |
| **N** 节点细胞 | 编排节点：executor/capability/入出参/审批/补偿 | hermes graph |
| **R** 规则细胞 | 阈值、公式、门禁、Playbook | policy / config / skill |
| **U** 界面细胞 | 页面区块、字段槽位、按钮、空态 | frontend |
| **A** 接口细胞 | method/path/req/resp/错误码 | api |
| **M** 指标细胞 | 指标定义 + 计算 + 数据源 + 告警 | analytics |
| **X** 集成细胞 | 外部系统：env/契约/失败语义 | adapters |
| **F** 经验细胞 | 经验条目字段 + 晋升 + 反哺动作 | evolution |
| **C** 合规细胞 | 人审/制裁/退订/假交付禁令 | gates |

**编号规则**：`域-类型-序号`（如 `ACQ-E-01` 获客实体1）

## 1.2 状态机细胞 S

### S-ACQ-01 Lead 状态机

```
discovered → enriched → osint_ok → qualified → contacted
    ↘ rejected(mock/invalid/dup)
qualified → nurturing
contacted → replied → linked_to_inquiry
contacted → silent → loss_recorded
任意 → suppressed(退订/制裁)
```

**守卫**：`contacted` 仅当 channel_mode=live 或人工确认；`qualified` 要求 grade∈{A,B} 或人工。

### S-ACQ-02 Outreach 发送机

```
draft → quality_checked → pending_review → approved → queued
     → sending → sent → delivered → opened → clicked → replied
sent → bounced | complained
pending_review → rejected
queued → cancelled
```

**守卫**：
- `PIPELINE_GATES_ENABLED=1` 时 step≤1 必须 pending_review  
- `suppression_hit` 禁止进入 queued  
- `simulated=true` 禁止 sending  
- persona 不一致 → 禁止 approved  

### S-ACQ-03 Inquiry/CRM 七步+扩展

```
new → triaged → qualifying → quoted → sampling → negotiating
→ pi_sent → deposit_paid → in_production → docs_ready
→ shipped → balance_due → won
任意 → lost(+loss_required)
won → after_sales → repurchase_loop
```

**守卫**：`pi_sent` 需资格字段齐或 override；`deposit_paid` 需 payment 凭证或人工；`shipped` 需物流节点。

### S-ACQ-04 Conversation 会话

```
open → active → waiting_customer | waiting_us
→ converted_inquiry → linked_order
→ closed
waiting_us 超时 SLA → escalate（提醒主管+跟单卡）
```

### S-ACQ-05 Slot（IP/指纹/账号）

```
unassigned → active → cooling → active
active → banned → recycled | scrapped
active → expired → renew_pending
```

### S-ACQ-06 ContentRun

```
draft → review → published → indexed → converting
published → deranked | removed
failed 保持 failed+原因
```

### S-ACQ-07 TaskGraph（爱马仕）

```
pending → validating → ready → dispatching → running
→ wait_human → running
→ succeeded | failed | skipped
failed → compensating → compensated | compensation_failed
```

### S-ACQ-08 Experience 晋升

```
raw →(≥3) validated →(≥5) pattern →(≥10) sop →(≥20 且有 biz 窗) skill_draft
skill_draft → evaluation → canary(5/25/50/100) → production
任意 → rolled_back
```

**守卫**：simulated 不晋 skill；无人审不进 production。

## 1.4 规则细胞 R（可配置阈值）

| 编号 | 规则 | 默认建议 |
|------|------|----------|
| R-01 | 首回 SLA | 24h；超时 escalate |
| R-02 | 自动进 contacted | 仅 live 发送成功 |
| R-03 | 资格四问缺失 | 禁 detailed quote，仅 range |
| R-04 | 评分深跟线 | score≥70 或 grade=A/B |
| R-05 | 制裁 | risk=sanctions → block all outreach |
| R-06 | 首封人审 | PIPELINE_GATES_ENABLED=1 **生产必开** |
| R-07 | 序列间隔 | D0/D3/D7/D14/D21 |
| R-08 | 退订 | suppression 永久有效（租户内） |
| R-09 | 新客定金提醒 | 默认提示 30%（Playbook 可覆盖） |
| R-10 | 印度新客 | playbook: full_prepay 倾向，先验付款 |
| R-11 | 同域名冲突人设 | block + merge 工单 |
| R-12 | mock 渠道 | UI 红标；不得进 production 经验晋升 |
| R-13 | 信任项发布 | 声称认证无图 → block；缺信任 → warn |
| R-14 | 询盘质量 A | 优先人跟，SLA 12h 可配 |
| R-15 | 信长度/CTA | quality_score&lt;60 回炉 |

# 第 6 篇 · 「细胞完成」定义（DoD）

一个细胞算完成，当且仅当：

1. **字段/状态/规则**写入本谱或代码常量  
2. **有实现**（表+服务+接口或前端）  
3. **有校验**（单测或 cert/冒烟）  
4. **失败诚实**（mock/degraded 可见）  
5. **进时间线/跟单卡/指标**至少一处可观测  
6. **不破硬锁**（登录/壳/色/ENV/八大子系统）
