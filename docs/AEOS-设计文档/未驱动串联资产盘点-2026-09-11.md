# 未驱动串联资产盘点 · 2026-09-11

> **目的**：回答「项目里有多少零件 / 智能体 / 中间件 / 散落功能，其中多少**没有被驱动串联起来**」。
> **方法**：三个并行子代理源码实测（智能体 / 中间件 / 散落功能三路）+ 可重跑脚本取数（`tools/capability_ledger.py` 串联率、`verify_executors.py` 执行器契约）。
> **口径**：「被驱动」= 被可达代码（路由 / worker / 主流程 / 执行器注册表）实际调用或注册；「未驱动」= 代码在但无生产调用点 / 未进编排链 / 不可达。
> **配套**：像素级盘点见 `官网像素级盘点报告-2026-09-10.html`；整车研判见 `家底盘点与整车研判-2026-09-10.md`。

## 八、结论

**"零件齐了、引擎装了、轮子没接、数据是空的"。** 未被驱动串联的资产大头是**后端 122 个可串联模块**（占 81%）与**42 个桩平台**（占 84%）——这两块接上就是真跑；前端 49 孤儿页 + 11 孤儿组件是**沉没资产**（并入主站或直接归档）；2 个摆设组件（vault / facade）与 1 个孤立项目（aionui）需决策接线或归档。**整条链缺的仍是：点火（端到端冒烟）+ 数据（灌种子）+ 接线（122 模块 + 42 平台）。**
