# DSH 万能皆可插 · 全流程场景插座矩阵

> **口号对齐**：Desktop Hermes 官方 —— **万能皆可插**  
> **基石**：外层 **DSH**（意图识别 + 技能包热插拔）= 行业万能插座基座  
> **编排**：内层 **爱马仕**（智慧调度指挥分派）+ 一系列智能体执行器  
> **覆盖**：租户入住付费 → AI 建站 → 内容 SEO/GEO/AAO → 视频多平台分发养号 → 获客 → 客户管理 → 销售成交回流发货 CRM  
> **日期**：2026-09-14

---

## 1. 一句话产品架构

```text
租户一句话需求 / 行业任意场景
        │
        ▼
┌──────────────────────────────────────┐
│  外层 DSH（万能插座基座）              │
│  意图识别 + 技能包(Skill)热插拔选拔    │
│  Persona/SOP 注入 → 产出任务图意图     │
└──────────────────┬───────────────────┘
                   ▼
┌──────────────────────────────────────┐
│  内层爱马仕（智慧调度指挥分派）        │
│  DAG / 审批 / Saga / 计费 / 取证      │
└──────────────────┬───────────────────┘
                   ▼
        任意编排插件（皆可插）
   建站 · 内容 · SEO/GEO/AAO · 视频
   分发养号 · 获客 · CRM · 履约物流
                   ▼
        租户可见结果 + 三轨计费 + 经验沉淀
```

**万能皆可插 = 不是万能代码，而是：万能意图入口 × 可插拔技能包 × 统一调度内核 × 标准执行器插座。**

## 3. 「万能皆可插」插座规格（技术对齐）

### 3.1 插座分层

| 层 | 插座类型 | 数量级 | 插拔方式 |
|----|----------|--------|----------|
| L-意图 | DSH Intent + 场景 scene_type | 无限（自然语言归一） | Normalizer + Skill Router |
| L-技能 | SKILL.md 技能包 | 76 业务 + 可扩展 | 目录热识别 / seed 入库 |
| L-专家 | AgencyZH Persona | 276+ | `persona_ref` 节点注入 |
| L-规约 | ECC SOP | 286+ | `sop_ref` 节点注入 |
| L-执行 | Hermes Executor | 24 | `ExecutorRegistry` |
| L-航道 | L1 场景模板（YAML） | 目标 ≥20 场景库 | 模板库热加载 |
| L-出站 | n8n Workflow | 按场景增长 | `workflow_registry` 薄出口 |
| L-渠道 | 发布平台 | 8 LIVE + 可扩 | publish_workers |

### 3.2 同一基座换行业（万能的真正含义）

```text
建材外贸（当前 Profile）
    │  Industry Profile 配置注入
    ▼
同一套：DSH + 爱马仕 + 执行器 + 计费 + CRM 骨架
    │
    ├─ 建材：BOQ 22 参数、岩棉/瓷砖计算器
    ├─ 电子：规格书、认证 SOP
    ├─ 机械：售后配件、技术问答
    └─ 其他：只换 Skill 包 + 词典 + 模板参数，不换内核
```

**万能皆可插的产品承诺**：换技能包和行业词典 = 换解决方案，调度内核与计费不重写。

## 5. 租户旅程（入住即插电）

```text
注册付费 ①
  → DSH 引导：「你是做什么产品的？」→ 自动挂行业 Skill 包
  → 爱马仕生成「开业任务图」：建站② → 首批文章③ → 首条视频分发④
  → 绑定域名/邮箱 → 获客开关⑤
  → 询盘进 CRM⑥ → 成交履约⑦
  → 每一步 Token/订阅/IP 槽位入账
  → 成功图写入经验 → DSH 下次推荐更准
```

**开业任务图**就是「万能皆可插」在租户侧的第一眼体验：不是空后台，是一条已排好的可批准流水线。
