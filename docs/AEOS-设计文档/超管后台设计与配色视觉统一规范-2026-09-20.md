## 1. ★ 核心裁定：玻璃态不是"满屏铺"，是"分场景用"

**裁定结论**：**看板主内容区用实底白卡；顶栏 / 侧栏 / 下拉面板 / 模态浮层用玻璃。**

**四条理由**（都可验证，非喜好）：

1. **性能**：`backdrop-filter` 是 GPU 重负载。此前已定"每屏玻璃 ≤3 个、玻璃叠玻璃 ≤2 层"。看板首屏有 6+4 个区块，全部玻璃必然掉帧。
2. **可读性**：数据密集区（金额、指标、图表）需要**稳定**的文字对比度。玻璃背后透色会让数值背景色漂移，对比度不可控。
3. **设计意图**：截图本身的气质就是**克制**——靠 1px 描边而非阴影/透明区分层次。满屏玻璃会破坏这个气质，变成"炫技"。
4. **层次**：玻璃的正确用途是表达**"浮在内容之上"**（顶栏、侧栏、浮层）。主内容区本身不是浮层，用玻璃反而语义错位。

**分工表**：

| 层级 | 手法 | 应用 |
|------|------|------|
| L0 页面底 | 薄荷渐变 + 2~3 个马卡龙光斑 | 全局（**玻璃的底衬，必做**） |
| L1 导航层 | **玻璃 thin** | 顶栏、左侧栏 |
| L2 内容层 | **实底白卡 + 薄荷灰描边 + 极轻阴影** | 6 张指标卡、四大区块卡 |
| L3 浮层 | **玻璃 thick** | 下拉面板、模态、抽屉、Tooltip |
| L4 强调 | **玻璃 mint** | 选中态、当前步骤、品牌高亮块 |

## 2. 逐条裁定结果（单真源）

| # | 维度 | 裁定 | 理由 |
|---|------|------|------|
| A1 | 页面底 | **看板/数据密集页用 `#EAF4F0`**；通用浅底备用 `#F7FBFA` | 卡片是白的，底色需**更明显的薄荷**才能拉开层次。`#EDF5F1` 与 `#E6F4F0` 是同一档，收敛为 `#EAF4F0` |
| A2 | 卡片底 | **实底 `#FFFFFF`**（内容层）；玻璃仅用于导航/浮层 | 见 §1 |
| A3 | 卡片描边 | **实底白卡 → 薄荷灰描边 `#E3EFEA`**；玻璃面板 → 白高光 `rgba(255,255,255,.70)` | **白卡不能配白描边**（浅底上不可见）。两套描边各归其位，冲突消解 |
| A4 | 圆角 | **卡片 `16px`**；玻璃浮层 / 模态 `18px`；按钮 `10px`；徽标 `999px` | 收敛为 4 档 |
| A5 | 阴影 | **实底卡 → `0 1px 2px rgba(31,74,66,.06)`**；玻璃浮层 → `0 8px 32px rgba(31,74,66,.10)` | 实底卡靠描边分层（截图口径对）；玻璃浮层无描边可见度，靠阴影（配色方案口径对） |
| A6 | 次级文字 | **`#55706B`**（对比度 5.14 ✅AA） | `#6B7F7A` 是目测取样无背书；`#55706B` 有实测数据 |
| A7 | 选中态底 | **`#DCF0EB`**（mint-100） | `#DFF3EA` 与它几乎同色，收敛为一 |
| A8 | 主色 | **`#4a9b8c`**（锁定不变） | `DESIGN-TOKEN-LOCK-01` |
| A9 | 实心按钮白字 | **用 `#367469`**（白字 5.44 ✅AA）；`#4a9b8c` 仅用于大号粗体白字 | 实测 `#4a9b8c` 白字仅 3.30 |
| A10 | 正文品牌色文字 | **用 `#2F6A5F`**（6.01 ✅AA） | 实测 `#4a9b8c` 当文字仅 3.17 |

### 3.1 字号与字重

| 角色 | 字号 | 字重 | 行高 |
|------|------|------|------|
| 页面主标题 | 24–32px | 500 | 1.25 |
| 区块标题 | 20px | 500 | 1.3 |
| 卡片标题 | 14px | 500 | 1.4 |
| 正文 / 标签 | 14px / 13px | 400 | 1.6 |
| 指标大数值 | 32px | 500 | 1.15 |
| 辅助说明 | 12px | 400 | 1.5 |

**字重仅用 400 / 500**。禁止 600、700 —— 马卡龙风格的柔和感会被粗体破坏。

### 3.2 字体配对（3 个选项，均零外链）

| 方案 | 正文字体 | 数字字体 | 适用 |
|------|---------|---------|------|
| **A（推荐）** | 系统无衬线栈 | 系统等宽 | 零外链、跨平台稳、加载零成本 |
| B | `"PingFang SC"` / `"Microsoft YaHei"` 优先 | 同上 | 中文观感更统一 |
| C | 系统无衬线 | `ui-monospace` 用于表格数字列 | 数据表对齐场景 |

> 不引入外部 Web Font：违反零外链约束，且中文 Web Font 体积过大。

## 4. 组件规范

### 4.1 指标卡 MetricCard

| 部分 | 规范 |
|------|------|
| 结构 | 标签（13px/次级色）→ 大数值（32px/500/主文字色）→ 环比趋势（可选） |
| 容器 | 实底白 · `--radius-card` · `--border-card` · `--shadow-card` · 内边距 `--s5` |
| 趋势 | 涨 `#AE3830`（红）/ 跌 `#24705A`（绿）—— **中国习惯**；缺失时**隐藏该位**，不留空 |
| 状态 | hover 抬升到 `--shadow-card-hover`；加载用骨架条；无数据显 `—` 而非 `0` |

### 4.2 流水线卡 PipelineStep（运营待办）

| 部分 | 规范 |
|------|------|
| 结构 | 步骤名（13px）→ 状态描述（12px/次级色）→ 数值（24px/500/主色 `--text-link`）→ 底部汇总（12px） |
| 连接 | 卡间用**内联 SVG 细线 + 箭头**表达推进；窄屏转纵向时连接线同步转竖向 |
| 当前步 | 用 `--glass-mint-bg` 底 + 主色描边 高亮 |

### 4.3 面积折线图 AreaChart（内联 SVG）

- Y 轴 5 条参考线 + 刻度；X 轴**月份必须连续**（此前截图漏 `Mar`，属缺陷）
- 折线 `--color-primary`，2px；面积填充 `--grad-area`
- 数据点圆点标记 + hover tooltip（日期 + 数值）
- **无障碍**：`aria-label` 概述 + **可展开的数据表格替代**（读屏可用）
- 无数据：显示空态插画 + 「暂无数据」，**不要画一条平的零线**

### 4.4 徽标 Badge / Chip

| 类型 | 底 | 字色 |
|------|-----|------|
| 中性 | `--bg-subtle` | `--text-secondary` |
| 强调 / 选中 | `--mint-100` | `--mint-800` |
| 成功 | `--color-success-soft` | `--color-success-text` |
| 警告 | `--color-warning-soft` | `--color-warning-text` |
| 危险 | `--color-danger-soft` | `--color-danger-text` |

- pill 圆角；**状态不得只靠颜色**，须叠加图标或文字（色盲友好）
- 国旗**用内联 SVG/CSS 绘制，禁用 emoji 国旗**（跨平台渲染不一致）

### 4.5 按钮

| 变体 | 底 | 字 | 对比度 |
|------|-----|-----|--------|
| Primary（含正文白字） | `--color-primary-strong` `#367469` | `#fff` | 5.44 ✅ |
| Primary（大号粗体白字） | `--color-primary` `#4a9b8c` | `#fff` | 3.30（仅 ≥18.66px bold） |
| Secondary | 白底 + `--border-card` | `--mint-800` | 6.01 ✅ |
| Danger | `--color-danger-text` | `#fff` | 5.43 ✅ |

- 最小点击区 **44×44px**；`:focus-visible` 焦点环 `0 0 0 3px var(--color-primary-soft)`

### 4.6 实底卡 vs 玻璃面板（对照）

| | 实底卡（L2 内容层） | 玻璃面板（L1/L3/L4） |
|---|---|---|
| 底 | `--bg-surface` `#FFFFFF` | `rgba(255,255,255,.52~.74)` + `blur()` |
| 描边 | `--border-card` 薄荷灰 `#E3EFEA` | `--border-glass` 白高光 `rgba(255,255,255,.70)` |
| 阴影 | `--shadow-card` 极轻 | `--shadow-float` 中 |
| 圆角 | 16px | 18px |
| 用在哪 | 指标卡、区块卡 | 顶栏、侧栏、下拉、模态 |

> **一句话记忆**：**白卡配灰边，玻璃配白边。** 白卡配白边在浅底上看不见。

## 5. UX 与状态规范

### 5.1 首屏信息层级（看板页）

1. **今天要处理什么** —— 待办/告警置顶，逾期标红
2. **关键数字是多少** —— 指标卡行
3. **趋势如何** —— 折线图
4. **明细在哪** —— 列表区块

### 5.2 五态（每个数据区块必须齐全）

| 状态 | 表现 | 文案示例 |
|------|------|---------|
| 加载 | **骨架屏**（非转圈，避免布局跳变） | — |
| 空 | 插画 + 说明 + 主操作按钮 | 「暂无线索，去发布内容获取询盘」 |
| 无结果 | 区别于空态（有筛选条件时） | 「没有符合条件的记录，试试放宽筛选」 |
| 错误 | 错误码 + 重试按钮 | 「加载失败（500），请重试」 |
| 无权限 | 锁图标 + 申请入口 | 「你没有查看该模块的权限」 |

### 5.3 无障碍（WCAG AA）

- 正文 ≥ **4.5:1**；大号数值 / 图形 ≥ **3:1**
- 全站 Tab 可达；焦点环始终可见（`:focus-visible`）
- 图表与纯图标按钮必须有 `aria-label`
- 状态不得只靠颜色区分
- 支持 `prefers-reduced-motion`（关闭动效）

### 5.4 响应式断点

| 断点 | 指标卡 | 区块 | 侧栏 |
|------|-------|------|------|
| ≥1440 | 6 列 | 2×2 | 常驻 |
| 1024–1439 | 3×2 | 2 列 | 常驻 |
| 768–1023 | 2 列 | 1 列 | 折叠 |
| <768 | 1 列 | 1 列 | 汉堡/底部 Tab；按钮 ≥44px；输入框 ≥16px |

## 6. 实施要点（给代码助手）

1. **Token 只有一份** —— 落一个 `tokens.css`（或 `design-tokens.ts`），组件**引用变量，禁止硬编码十六进制**。
2. **白卡 / 玻璃分工要落到组件层** —— 建议两个基础组件：`<SurfaceCard>`（实底）与 `<GlassPanel>`（玻璃），不要各页面自己写。
3. **玻璃的底衬必做** —— 页面根节点铺 `--grad-canvas` + 2~3 个马卡龙光斑；没有底衬的地方**不要用玻璃**。
4. **降级** —— `@supports not (backdrop-filter: blur(1px))` → 玻璃退化为 `rgba(255,255,255,.92)` 实底。
5. **文案语义化** —— 设计截图中的占位假文案（错拼、重复、`Subtitle: 56`）一律替换；含义不确定的字段保留占位 + `TODO`，**不要编造**。
6. **灰度自检** —— 交付前把界面转灰度看一遍：若层次仍清晰，说明没有过度依赖颜色，合格。
