## 算法落地（严格按文档权重）
1. **硬条件过滤（Eligibility，确定性，LLM 不得覆盖）**：防火等级低于要求、导热系数超过上限 → 直接 REJECT 并给理由。
2. **8 维加权评分**：fireRating 0.30 / standard 0.20 / application 0.15 / environment 0.10 / market 0.10 / installation 0.05 / commercial 0.05 / availability 0.05 → 总分 0~100。
3. **证据 + 解释 + 分级**：每条匹配返回 `evidence`（判定依据）、`explanation`（中文推荐理由）、`tier`（推荐≥75 / 备选 55-74 / 不推荐<55）。**未编造任何认证/测试数据**，只基于真实 Product 字段与用户输入。
