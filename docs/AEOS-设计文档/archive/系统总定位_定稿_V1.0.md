# AI Global Growth OS · 系统总定位（定稿）

> 本文档为全部规划文档的上位纲领。任何后续设计、集成、开发决策与本定位冲突时，以本定位与《三方文档对峙与合并结论》冻结基准为准。

## 一、一句话定位（定稿）

这是一套以 **DeepSeek Harness + Hermes 双层智能编排**为核心、以 **ECC 专家知识和 Skills/MCP/Plugins** 为可进化能力底座，以 **DeerFlow、n8n、Browser Runtime** 为执行基础设施的 **AI 全球增长与成交操作系统**——客户只需提供产品和一句自然语言需求，系统即可从建站、内容生产、多平台分发、SEO/GEO/AEO/AIO、GoodJob 获客、线索培育、AI 开发信到促单成交形成完整闭环，并将每次真实业务结果沉淀为可复用经验，让系统越用越聪明、客户越用越简单、成交越多、平台收入越高。

## 二、术语冻结（不得漂移）

| 术语 | 定义 | 废弃别名 |
|---|---|---|
| Control Plane | 优丁 FastAPI 单体（224 表），唯一业务真相源与调度主权 | "AI Revenue OS 后台" |
| DeepSeek Harness | 外层 Agent Runtime，仅 Adapter 桩（未 GA 不启用） | "DeepSeek Hermes" |
| Hermes | 内层编排模块（`app/services/hermes/`），任务理解/拆解/路由/护栏 | "外层智能层""Nous Hermes" |
| ECC | 专家能力层伞概念 = Skills + SOP + 验证器 + 专家面板 + 行业知识包 | "Execution Context Container" |
| DeerFlow / n8n / Browser Runtime | Execution Plane 平级 Adapter | "Accio 终端执行器" |
| Accio | 外贸获客业务能力（`ubrain/accio_*`），属业务服务而非运行时 | "Work Runtime" |
| 底座插件化 | 任意行业（建材/机械/任意产品）以 ECC 行业包 + 行业 Skill 插入同一底座 | — |

## 三、闭环链路总图

```
产品 + 一句自然语言
   ↓
建站（site_builder）→ 内容生产（content_master + 清洗/复核双关卡）
   ↓
多平台分发（unified_publish + 四链路 Pipeline + 步级 Evidence）
   ↓
SEO / GEO / AEO / AIO（geo_engine / aeo_fact_audit / ai_visibility）
   ↓
GoodJob 获客（链路整合：模式提炼为主，整仓收编可选）
   ↓
线索培育（nurture + drip）→ AI 开发信（ubrain outreach + follow_up，WhatsApp 官方通道规划中）
   ↓
促单成交（RFQ → Quote → Opportunity → Payment）
   ↓
经验沉淀（task_traces → ExperienceEntry → Canary → 人审 → Skill 版本升级）
   ↓
更聪明 → 更简单 → 更多成交 → 平台收入（meter_events → Revenue OS）
```

## 四、价值飞轮（三句话）

1. **系统越用越聪明**：每次真实执行与成交结果都经 Evidence 验证后进入经验库，经灰度与人审升级为版本化 Skill。
2. **客户越用越简单**：行业 ECC 包持续加厚，同类任务的关卡规则、话术、渠道策略自动复用。
3. **平台收入越高**：成交越多 → 计量事件越多 → 订阅/用量/线索/佣金多管道收入放大。
