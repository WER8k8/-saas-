## 二、四大一级基础设施（v3 新增）

### 2.1 Agent Governance Layer（L1.5 Policy Engine）
- 风险等级 R0–R5（R0 只读 → R5 不可逆资金/删除）
- Tool Capability Token：每调用校验 token × 租户 × R 级
- L1.5 插入 L1（认知）与 L2（调度）之间，做 **静态拓扑 + 动态策略双闸**
- Kahn/Tarjan 环路拦截保留（L2 Hermes 状态机已实装），新增 Policy 前置

### 2.2 Reliability Backbone
- Outbox / Inbox：跨 executor 出站、入站消息表
- DLQ 死信：失败 3 次进死信，保留原始 payload + 重试语义
- Idempotency：每个 executor 调用带 idempotency_key，Redis 7.x + PG 双写
- Saga：7 步履约（询盘→PI→定金→生产→单证→尾款→物流）作为 Saga 编排，每步可补偿

### 2.3 Evaluation Framework
- Eval Contract：每个 L1 意图有 expected_output_schema + golden 样本
- RAG 分阶段：先 9 意图 deep research → 再 350+ 资产向量召回
- 评测指标：串联率（现 17.3%）/ 能力覆盖（47 能力）/ 真跑成功率

### 2.4 Metering Shadow Mode + 幂等 Billing
- 三轨计费：SaaS 订阅 + AI Token（Token Wallet Guard 实时拦截）+ 静态 IP/指纹槽位
- Phase1 Shadow：计量落库但不扣费，对齐 30 天后转正式
- 幂等：billing executor 带 idempotency_key，重放不重复
