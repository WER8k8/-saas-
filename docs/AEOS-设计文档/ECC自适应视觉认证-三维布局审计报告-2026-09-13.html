视觉架构与响应式设计审计

Material Design 3 合规 / WCAG 2.2 AA / 排版系统 / 动效规范

94
/ 100
响应式断点策略
6 断点(xs/sm/md/lg/xl/2xl)覆盖 320px-2560px 全区间，与 Material Design 3 断点系统对齐。clamp() 字号公式确保流式缩放无跳变。
PASS
排版层级系统
官网 7 级(display/h1/h2/h3/body/small/caption) + Admin 8 级(xs~3xl)，通过 --adaptive-scale 统一缩放。行高/字重层级清晰。
PASS
动效减弱支持
@media (prefers-reduced-motion: reduce) 已覆盖，动效级别 4 档(none/reduced/normal/rich)与角色画像联动。Accessibility 模式自动降级。
PASS
高对比度模式
@media (prefers-contrast: more) 已覆盖，文本/边框强制最大化对比度。薄荷主色 #4a9b8c 在 WCAG AA 大文本对比度 >= 4.5:1。
PASS
触摸目标尺寸
@media (hover: none) and (pointer: coarse) 下触摸目标 >= 44px，符合 WCAG 2.2 AA 2.5.8 Target Size 要求。
PASS
CSS 变量命名一致性
官网 --sb-* 前缀、Admin --uj-* 前缀，两套系统独立不冲突。但 composable 输出的 CSS 变量名已与 SCSS 令牌对齐（--uj-adaptive-scale）。
PASS
打印样式
官网 @media print 已处理：隐藏 header/footer/浮动按钮，缩放因子归 1。Admin 端打印样式可进一步加强。
MINOR
I 英特尔技术总监 — 性能与安全审计
I

运行时性能与跨浏览器兼容性审计

CSS 计算开销 / 内存泄漏 / XSS 防护 / 浏览器兼容性

91
/ 100
CSS calc() 性能
所有 calc() 表达式仅涉及 CSS 变量乘法，浏览器渲染引擎可在 1 帧内完成。无嵌套 calc()，无 JS-driven layout thrashing。resize 事件已 debounce (200ms)。
PASS
localStorage 安全
仅存储枚举值(persona ID/scenario mode/font level)，无用户输入拼接，无 JSON.parse 风险。SSR 环境有 typeof localStorage 守卫。
PASS
XSS 防护
CSS 变量值全部为数值或预定义枚举，无 v-html 风险。style 绑定通过 Vue computed 返回对象，自动转义。
PASS
内存泄漏防护
onUnmounted 正确移除 resize 事件监听和定时器。watch 使用 Vue 响应式系统自动管理生命周期。
PASS
跨浏览器兼容
CSS custom properties: Chrome 49+/Firefox 31+/Safari 9.1+。clamp(): Chrome 85+/Firefox 75+/Safari 13.1+。matchMedia: 全平台支持。
PASS
GPU 加速评估
无 will-change 滥用，无 transform 触发合成层爆炸。自适应控制面板使用 backdrop-filter 仅在展开时生效，影响范围可控。
PASS
Service Worker 兼容
Admin 端 SW 注册仅在 /client 路径下，自适应状态存 localStorage 不受 SW 缓存影响。
PASS

展会现场模式
Exhibition 模式：侧栏隐藏、密度最低、通知静默。在广交会/法兰克福展等场景下，用平板快速展示产品目录，切换流畅。字号自动放大到 1.12x 适应站立距离观看。
PASS
工厂车间巡检
Mobile-Field 模式：手机单手操作，核心功能(inquiries/copilot)优先。车间光线强时高对比度模式自动激活。触摸目标 >= 44px 戴手套可操作。
PASS
多语言客户展示
RTL 语言(ar-SA)自动切换 dir="rtl"。12 语种 i18n 全覆盖。Presentation 模式隐藏无关功能，专注数据展示给客户。
PASS
弱网环境适应
CSS 变量方案零网络开销（纯客户端计算）。localStorage 持久化避免重复初始化。AdaptiveControls 组件 < 3KB gzip。
PASS
跨时区长时间使用
Focus 模式减少视觉疲劳（侧栏隐藏、密度适中）。Accessibility 模式大字号 + 减弱动效适合深夜加班。用户偏好自动保存，刷新不丢失。
PASS
新手外贸业务员
Beginner 模式：大字体(1.15x)、大图标、全引导提示、隐藏高级功能。避免信息过载，降低学习曲线。3 天内可独立完成基础询盘处理。
PASS
老外贸/管理层
Expert 模式：紧凑密度、小图标、零动效。一屏显示最多数据，快速扫描全局。Power 模式平衡信息密度与可读性。
PASS
不同屏幕尺寸设备
从 320px 旧手机到 2560px 4K 显示器全覆盖。展会用 iPad(768px)、车间用手机(375px)、办公室用笔记本(1366px)/外接屏(1920px+)，自适应切换无感。
