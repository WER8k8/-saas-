03

接入方式

环节做法
磁吸配置buildSnapCursor() 返回 tooltip / xAxis / seriesEmphasis 片段，浅合并进既有 option，不整体替换
游标值订阅useChartCursor(resolve) 给出 activeIndex / activeValue，绑定 <v-chart ref> 实例
码表联动activeValue 直接喂给 useCountUp（已修复为补间）
配色读设计令牌 --uj-brand，不硬编码（项目主色按壳切换，硬编码会破坏 agent 壳）
无障碍降低动态效果时自动关闭吸附动画与呼吸光晕
接入前必做8 个图表文件用 use([...]) 按需注册，均未注册 AxisPointerComponent：仅 tooltip 驱动可用；若要常驻指示线须补注册
