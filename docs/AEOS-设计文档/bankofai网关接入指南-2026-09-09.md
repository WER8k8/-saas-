## 2. ⚠️ 必需：代理绕过

本机存在系统代理 `127.0.0.1:7897`。部分情况下到 bankofai 的 POST 会报：
`400 The plain HTTP request was sent to HTTPS port`（TLS/SNI 错配）。

**解决**：在代理客户端（Clash/v2ray 对应的 7897 实例）把下面加入**直连/绕过名单**：

```
api.bankofai.io
```

> 2026-09-09 实测：走当前网络直连 `Invoke-RestMethod` 亦可通，未复现上述错误；但为稳定建议仍加直连。

## 3. 配置到各工具

### 3.1 CC Switch（model 供应商切换器）
1. 打开 CC Switch → **添加 Provider / 新增供应商**
2. 类型选 `custom / OpenAI 兼容`（照已有 `experientiallabs`、`unorouter` 样式）
3. 填 §1 的 5 项，默认模型 `qwen3.8-flash`
4. 保存 → 在 Claude/Codex 的 provider 下拉切到 `bankofai` 验证
5. 界面无代理项的，走 §2 系统代理绕过

### 3.2 OmniRoute 网关
1. 控制台 → **新增上游节点/连接（NewAPI / OpenAI 兼容）**
2. Base URL `https://api.bankofai.io/v1`，API Key `sk-1gp…nhf`
3. 命名 `bankofai`，默认模型 `qwen3.8-flash`
4. 全局代理加直连 `api.bankofai.io`
5. 建 combo/路由把 `bankofai/qwen3.8-flash` 设为默认

### 3.3 TRAE 自定义模型（OpenAI 兼容）
1. 设置 → 模型 → 添加 OpenAI 兼容供应商
2. 填 §1 参数，默认模型 `qwen3.8-flash`
3. 代理绕过项同 §2

## 4. 自检命令（一条验证网关是否通）

```powershell
$h=@{ Authorization="Bearer sk-***REDACTED***" }
$b='{"model":"qwen3.8-flash","messages":[{"role":"user","content":"Reply OK"}],"max_tokens":8}'
Invoke-RestMethod -Uri "https://api.bankofai.io/v1/chat/completions" -Method Post -Headers $h -ContentType "application/json" -Body $b -TimeoutSec 60 | % { $_.choices[0].message.content }
```

- 返回 `OK` → 网关通，可正常使用。
- 报 `400 plain HTTP...HTTPS port` → 代理未绕过，去 §2。
- 报 `insufficient_user_quota` → 该模型需充值额度。
- 报 `access_denied ... Deposit required` → 该模型是高级付费款，需充值解锁。
