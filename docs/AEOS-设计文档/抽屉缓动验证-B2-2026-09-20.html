01

为什么不用弹性过冲曲线

抽屉是贴边锚定的。曲线的过冲量作用在位移轴上时，元素会「穿过」目标位置—— 对居中的卡片是无害的抖动，对贴边面板却是物理穿帮。

  • 右侧抽屉静止位 translateX(0)，面板右边缘与视口右边缘重合。
  • 过冲意味着 translateX 变成负值 → 面板整体左移 → 右侧露出遮罩。
  • 幅度按抽屉宽算，不是固定像素：过冲 12% × 378px ≈ 45px，肉眼极明显。
  • 左 / 上 / 下三个方向同理，各自在锚定边露缝。这是几何必然，与曲线参数无关，只能靠「不过冲」规避。
  • 真正需要弹性回弹的是 #5 阻尼 Bottom Sheet：那是手势驱动的，由松手速度决定吸附锚点，属于另一批次。

否决记录：cubic-bezier(.34,1.56,.64,1) 这类「back-out」曲线在落地页/作品集里很好用， 但对本项目 14 个抽屉全部不适用。已从方案中移除，不作为备选项保留。

落地代码（已写入仓库）

文件：frontend/admin/src/styles/motion-v4-macaron.scss §4。 机制来自实测：AntD 把缓动写死在 CSS 里，没有对应 theme token，所以只能覆盖。 

/* 单点开关：4 个变量改回 ease / 300ms 即完全复原 AntD 原生手感 */
:root {
  --uj-drawer-enter-ease: cubic-bezier(0.16, 1, 0.3, 1);   /* expo-out：进入 */
  --uj-drawer-enter-duration: 340ms;
  --uj-drawer-leave-ease: cubic-bezier(0.7, 0, 0.84, 0);   /* expo-in：退出 */
  --uj-drawer-leave-duration: 200ms;
}

/* 位移层 · 进入（html 前缀是必需的，见下方说明）*/
html .ant-drawer .ant-drawer-content-wrapper {
  transition: transform var(--uj-drawer-enter-duration) var(--uj-drawer-enter-ease);
}

/* 位移层 · 退出：一个属性选择器覆盖 left/right/top/bottom 四个方向 */
html .ant-drawer .ant-drawer-content-wrapper[class*='-leave-active'] {
  transition: transform var(--uj-drawer-leave-duration) var(--uj-drawer-leave-ease);
}

/* 初始落位那一帧必须无过渡，否则会从上一个位置滑进来 */
html .ant-drawer .ant-drawer-content-wrapper[class*='-enter-start'],
html .ant-drawer .ant-drawer-content-wrapper[class*='-appear-start'] {
  transition: none;
}

/* 动画期间才提升为合成层，类名一撤即自动释放 */
html .ant-drawer .ant-drawer-content-wrapper[class*='-enter-active'],
html .ant-drawer .ant-drawer-content-wrapper[class*='-leave-active'] {
  will-change: transform;
}

/* 遮罩层同步曲线与时长，避免「面板已到位、遮罩还在淡入」的割裂感 */
html .ant-drawer .ant-drawer-mask-motion-enter-active,
html .ant-drawer .ant-drawer-mask-motion-appear-active {
  transition: opacity var(--uj-drawer-enter-duration) var(--uj-drawer-enter-ease);
}
html .ant-drawer .ant-drawer-mask-motion-leave-active {
  transition: opacity var(--uj-drawer-leave-duration) var(--uj-drawer-leave-ease);
}

为什么选择器要加 html 前缀

1. 抽屉默认 portal 到 body，.shell / .yd-page 这类祖先选择器全部落空；

2. AntD 样式由 cssinjs 运行时注入，位于静态样式之后，同权重时靠后者取胜；

3. 加一个元素选择器 → 特异性 (0,2,1) 稳压 AntD 的 (0,2,0)，无需 !important。

影响面与回滚

· 覆盖 14 个文件的抽屉（含 ThemeSettingsDrawer.vue），是行为变更而非纯增补；

· 回滚 = 把 4 个变量改回 ease / 300ms，或整段删除；

· 已接入 prefers-reduced-motion 降级：降低动态效果时直接落位。
