# P2 平台凭据矩阵 · 收口决策

> 依据实扫 `tools/platform_credential_scan.py` + 产出 `tools/platform_credential_matrix.json`（2026-09-12）
> 关联：v3 总案 F18（无凭据降级 mock，诚实标记）/ `docs/50平台接线台账-2026-09-10.md` / 硬锁 ENV-LOCK-01

---

## 一、实扫结论（DB 真值）

| 维度 | 数值 | 说明 |
|------|:---:|------|
| platforms 表 | **50 行** | catalog 应注册 50（CN 20 + GLOBAL 21 + B2B 5 + B2C 4），**DB 与 catalog 完全对齐，无未注册缺口** |
| 平台能力分层 | LIVE 8 / 文本适配 7 / 桩 ≈35 | 8 真发：Facebook/Instagram/X/LinkedIn/YouTube/微信公众号/头条号/知乎 |
| platform_accounts | **仅 4 壳** | 微信公众号 / 抖音 / YouTube / 哔哩哔哩，各 1 个 |
| 实绑定（logged_in/bound） | **0** | 4 壳全部 `login_status=logged_out`，无真凭据 |
| platform_configs | **0 行** | 4 件套（OAuth/Cookie/API）凭据键 **0 填充** |
| DB 桩平台（active 非 LIVE/TEXT） | **45** | 这些平台既无 account 壳也无 config |

**核心判定**：P2 当前不是「代码未写」，而是「**凭据矩阵全空**」——50 平台已注册、4 账号壳已建、发布就绪服务（`publish_readiness_service`）判定逻辑已就绪，但真实凭据 0 填充。`ready_to_publish` 会因 `bound_accounts==0` 而恒为 False。

## 二、降级 mock 契约（v3 F18 落点）

| 场景 | 行为 | 契约要点 |
|------|------|----------|
| 缺凭据（45 桩平台 + 4 未绑定壳） | `UnimplementedPublisher` **明确失败** | **不得冒充 success**，返回 `mock=True` + 记 `meter_events` |
| 部分凭据 | 降级 mock + 标记 | `on_partial_credentials` → 返回 `mock=True`，不静默假成功 |
| WhatsApp | `key=whatsapp_business`，缺 key 降级 stub | 非假发，Evidence 缺则回退 |
| Reddit | 无 OAuth 公开写 API，降级 stub | 诚实标记不可发 |

> 原则（v3 §五）：**模型/Executor/Provider 可换；但治理、幂等、审计、计量、证据、租户隔离不能换。** 缺凭据可降级，但 `mock=True` 标记 + 计量留痕不可省。

## 三、收口动作清单（P2 达标路径）

| 优先级 | 动作 | 交付物 | 依赖 |
|:---:|------|--------|------|
| P0 | 为 8 个 LIVE 平台注入真凭据（OAuth 4 件套或 Cookie） | platform_configs 落库 + `login_status=logged_in` | 人工提供真实账号（人工阻塞项） |
| P1 | 4 账号壳升级绑定（微信/抖音/YouTube/哔哩哔哩） | `upsert_bound_account` 走 bound 路径 | 人工登录取证 |
| P2 | 45 桩平台挂 `UnimplementedPublisher` 兜底 | 发布时诚实 mock，不报「已收录」 | 无，可即刻做 |
| P3 | 发布门禁校验 `ready_to_publish` 证据链 | `publish_readiness_service` 返回非空 `next_actions` | 上述凭据到位 |

> **人工阻塞项**（Codex/Agent 无法替代）：真实平台凭据须人工登录 + 取证。Agent 可即刻做的是「桩平台兜底 + mock 契约固化 + 发布门禁证据链」，把 P2 从「全空」推进到「可发 8 真发平台 + 诚实 mock 其余」。

## 四、与四门禁/自检对齐

- `fake_scan.py`：缺凭据走 mock 属**诚实降级**（LOW 级标记），不计 HIGH 假成功 → 门禁保持 PASS。
- `orchestration_selfcheck.py`：「真执行接线 0 占位」项需桩平台挂 `UnimplementedPublisher` 后，发布路由不再指向空桩 → 该项保持 19/19 全绿。

---

**结论**：P2 瓶颈定位为「**凭据矩阵全空**」（非代码缺失）。代码侧（平台注册/账号壳/发布就绪/mock 契约）已就绪，唯一卡点是真实凭据注入——属人工阻塞项。Agent 侧可自主推进的收口 = 桩平台 `UnimplementedPublisher` 兜底 + 发布门禁证据链 + mock 计量留痕。
