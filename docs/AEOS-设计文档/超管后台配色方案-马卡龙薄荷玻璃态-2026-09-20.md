# 优丁 YouDing · 马卡龙薄荷玻璃态配色方案 v1.0

> 日期：2026-09-20 ｜ 适用：浅色主题（Light Theme）
> 硬约束：遵守 `DESIGN-TOKEN-LOCK-01` —— 平台主色锁定 **`#4a9b8c`**。
> **本方案的做法是「以锁定色为深端锚点向下派生马卡龙浅色阶」，而不是更换主色。** 锁未破。
> 所有对比度数值均为**实测**（WCAG 2.1 相对亮度公式），非估算。测量脚本见 §7。

---

## 一、设计定位

| 维度 | 定义 |
|------|------|
| 风格 | **正统马卡龙（Macaron / Pastel）** —— 高明度、低饱和、奶感柔光 |
| 主色调 | **薄荷浅色**（Mint），锚定品牌色 `#4a9b8c` |
| 视觉手法 | **玻璃态（Glassmorphism）** —— 背景模糊 + 半透明 + 白色高光描边 |
| 主题 | 浅色主题（深色主题不在本方案范围，且被令牌锁禁止切换） |

**马卡龙风格的量化守则**（避免"做成荧光色"或"做成莫兰迪"）：

- 饱和度区间：HSL 的 **S = 35% ~ 55%**（过低变灰、过高变荧光）
- 明度区间：HSL 的 **L = 78% ~ 92%**（马卡龙 = 奶感高明度）
- **禁止纯黑纯白作前景**：文字最深用 `#1E3330`（深薄荷墨），最浅底用 `#F7FBFA`
- **主色占比 ≤ 30%**，单个辅助色 ≤ 10%，其余留白
- **同屏辅助色 ≤ 3 种**（马卡龙五色不是让同时上）

## 五、玻璃态（Glassmorphism）规格

### 5.1 四档玻璃（按用途分级）

| 档位 | 用途 | 背景色 | 模糊 | 边框 | 阴影 |
|------|------|--------|------|------|------|
| `glass-thin` | 顶栏 / 工具条 | `rgba(255,255,255,0.45)` | `blur(12px) saturate(150%)` | `1px solid rgba(255,255,255,0.55)` | `0 1px 0 rgba(255,255,255,0.60) inset` |
| `glass-regular` | 卡片 / 面板 | `rgba(255,255,255,0.58)` | `blur(20px) saturate(170%)` | `1px solid rgba(255,255,255,0.70)` | `0 8px 32px rgba(31,74,66,0.10)` + `inset 0 1px 0 rgba(255,255,255,0.85)` |
| `glass-thick` | 模态 / 抽屉 | `rgba(255,255,255,0.72)` | `blur(28px) saturate(180%)` | `1px solid rgba(255,255,255,0.80)` | `0 16px 48px rgba(31,74,66,0.14)` + `inset 0 1px 0 rgba(255,255,255,0.90)` |
| `glass-mint` | 品牌强调玻璃 | `rgba(74,155,140,0.14)` | `blur(18px) saturate(160%)` | `1px solid rgba(74,155,140,0.24)` | `0 6px 24px rgba(74,155,140,0.12)` |

### 5.2 四个必守处理手法

**① 模糊（blur）**
- 范围 **12px ~ 28px**。低于 12px 看不出玻璃感，高于 28px 拖累 GPU 且色块糊成一片。
- 必须配 `saturate(150%~180%)`：背后马卡龙色透过时不发灰，这是"奶感"的关键。

**② 透明度（alpha）**
- 白玻璃 alpha **0.45 ~ 0.72**。低于 0.45 文字可读性崩，高于 0.75 等于不透明白卡。
- **透明度与文字深度成反比**：越透明 → 背景色影响越大 → 文字必须越深。最坏情况按 §6 的 `#F2F8F6` 等效底校验。

**③ 边框（border）—— 玻璃态的灵魂**
- **用白色高光描边，不要用灰色描边**：`rgba(255,255,255,0.55~0.80)`。
  灰描边会把玻璃"框死"，白描边模拟玻璃边缘反光。
- 厚度固定 **1px**；不要 2px（显笨重）。
- 加分项：顶部内高光 `inset 0 1px 0 rgba(255,255,255,0.85)` 模拟玻璃厚度。

**④ 底衬（必做，否则玻璃失效）**
> **玻璃必须叠在「有颜色或有纹理」的底上才成立。纯白底上的玻璃 = 白卡片。**

页面底必须铺：`--grad-hero` 薄荷渐变 + **2~3 个马卡龙光斑（blob）**：

```css
.blob { position:absolute; border-radius:50%; filter:blur(60px); opacity:.55; }
.blob-a { width:520px; height:520px; background:#A0D6CB; top:-120px; left:-80px; }
.blob-b { width:420px; height:420px; background:#D9CDF0; top:30%;  right:-100px; }
.blob-c { width:460px; height:460px; background:#FBE3A8; bottom:-140px; left:35%; }
```

### 5.3 玻璃上的文字规则

| 文字角色 | Token | 在玻璃底（等效 `#F2F8F6`）实测 |
|---------|-------|------------------------------|
| 主文字 | `--text-primary` `#1E3330` | **12.43** ✅ 任意字号 |
| 次文字 | `--text-secondary` `#55706B` | **4.99** ✅ ≥14px |
| 三级文字 | `--text-tertiary` `#7A9691` | **2.96** ⚠️ **仅 ≥18.66px bold 或纯装饰** |

> **三级文字不可承载关键信息**（如"共 128 条"这类必须读到的数据）。这是实测硬约束，不是偏好。

### 5.4 降级与性能

- **不支持 backdrop-filter 时**（`@supports not (backdrop-filter: blur(1px))`）：
  背景 alpha 提升到 **0.92**，改用 `--bg-surface` 实底，保证可读性优先。
- **`prefers-reduced-transparency: reduce`** → 全部玻璃退化为不透明面板。
- **`prefers-reduced-motion: reduce`** → 关闭光斑视差与 hover 位移。
- **每屏玻璃层 ≤ 3 个**；玻璃上**再叠玻璃不超过 2 层**（backdrop-filter 叠加是 GPU 重灾区，移动端会掉帧）。

### 6.2 ⚠️ 两个必须避开的坑（实测数据）

**坑 1：白字压品牌主色只有 3.30，不够 AA 正文。**

| 白字压在 | 实测对比度 | 判定 |
|---------|-----------|------|
| `#4a9b8c`（品牌主色） | **3.30** | ⚠️ 仅 ≥18.66px bold 可用 |
| `#3F8779`（mint-700） | 4.24 | ⚠️ 仍不够正文 AA |
| `#367469`（**推荐实心按钮色**） | **5.44** | ✅ 正文 AA |
| `#2F6A5F`（mint-800） | 6.27 | ✅ 稳妥 |

**解法**：新增语义令牌 `--color-primary-strong: #367469`。
- **实心按钮（白字）** → 用 `--color-primary-strong` `#367469`，白字达 5.44 ✅
- **装饰块 / 图标 / 大标题底** → 可继续用 `#4a9b8c`，但白字必须 **≥18.66px 且 bold**

**坑 2：品牌主色当"正文文字"用在浅底上只有 3.17，不合格。**

| 当作文字的色 | on `#F7FBFA` | 判定 |
|-------------|-------------|------|
| `#4a9b8c` | **3.17** | ❌ 不能做正文链接 |
| `#3F8779` | 4.07 | ⚠️ 仍差 |
| `#2F6A5F` | **6.01** | ✅ 用这个 |

**解法**：正文里的品牌色文字/链接**统一用 `--text-link: #2F6A5F`**，不要直接拿 `#4a9b8c` 当文字。

## 七、实测数据与复现

所有对比度按 **WCAG 2.1** 计算：

```python
def lin(c):
    c /= 255.0
    return c/12.92 if c <= 0.03928 else ((c+0.055)/1.055)**2.4

def L(hex_):
    h = hex_.lstrip('#')
    r, g, b = (int(h[i:i+2], 16) for i in (0, 2, 4))
    return 0.2126*lin(r) + 0.7152*lin(g) + 0.0722*lin(b)

def contrast(a, b):
    la, lb = L(a), L(b)
    hi, lo = max(la, lb), min(la, lb)
    return round((hi + 0.05) / (lo + 0.05), 2)
```

阈值：正文 AA ≥ **4.5**；大字（≥18.66px bold 或 ≥24px）≥ **3.0**；UI 组件/图形 ≥ **3.0**。

**边框说明（重要）**：玻璃白边框与底色的对比度实测仅 **1.05**，这是**正常的**。
玻璃边框是**装饰性反光**，不是信息承载元素 —— 因此不适用 3:1 组件对比度要求。
**但**：凡是"靠边框区分状态"的组件（输入框、选中项），必须**额外**给出非边框的冗余线索（底色变化 / 图标 / 文字），不能只靠玻璃边框。

## 九、使用禁忌（做成"廉价玻璃"的常见原因）

| ❌ 禁忌 | 为什么 | ✅ 正确做法 |
|--------|--------|-----------|
| 纯白底上用玻璃 | 玻璃=白卡片，完全无效 | 底必须铺薄荷渐变 + 马卡龙光斑 |
| 灰色描边做玻璃边框 | 把玻璃"框死"，失去通透感 | 白色高光描边 `rgba(255,255,255,.55~.8)` |
| `blur` 给到 40px+ | 糊成一片 + 掉帧 | 12~28px |
| 不带 `saturate()` | 背后色彩发灰，没有奶感 | 补 `saturate(150%~180%)` |
| 玻璃上直接放浅灰字 | 对比度崩（`#7A9691` 仅 2.96） | 用 `--text-primary`/`--text-secondary` |
| 拿 `#4a9b8c` 当正文链接色 | 3.17 不合格 | 用 `--text-link:#2F6A5F` |
| 白字压 `#4a9b8c` 做正文按钮 | 3.30 不合格 | 用 `--color-primary-strong:#367469` |
| 同屏 5 个辅助色全上 | 马卡龙变"儿童乐园" | 同屏 ≤3 种 |
| 玻璃叠玻璃 3 层以上 | GPU 重灾区，移动端掉帧 | ≤2 层，每屏玻璃 ≤3 个 |
| 用纯黑 `#000` 做遮罩 | 画面发脏、失柔和 | `rgba(30,51,48,.28)` 深薄荷墨 |
