## 一、能力映射（核心）

ECC 原文要求「无需用户提示就用 planner / code-reviewer / tdd-guide …」，但本环境可用的 agent 只有 6 个：`claude`、`Explore`、`general-purpose`、`Plan`、`statusline-setup`、`claude-code-guide`。

## 二、实质条款（照做）

1. **不可变性优先**——Python 用 `@dataclass(frozen=True)` / `NamedTuple`；**例外**：SQLAlchemy ORM 模型必须可变。
2. **规模上限**——文件 ≤800 行、函数 <50 行、嵌套 ≤4 层。
3. **错误处理**——每层显式处理，**绝不静默吞异常**；UI 友好消息 + 服务端详细上下文。
4. **输入验证**——系统边界处验证，不信任外部数据。
5. **提交前安全清单**——无硬编码密钥、参数化查询、HTML 净化、CSRF、鉴权、限流、错误不泄密。
6. **测试**——pytest，`pytest.mark.unit/integration` 分类；TDD（RED → GREEN → IMPROVE）。
7. **模式**——Repository 模式封装数据访问；API 统一 envelope（status + data + error + 分页元数据）。
8. **上下文管理**——剩最后 20% 时避免大重构 / 跨文件实现 / 复杂调试。
9. **提交信息**——Conventional Commits。
