| 阶段 | 比例 | 持续时间 | 监控项 | 决策标准 |
|------|------|----------|--------|----------|
| F.1 | 5% | 24h | error rate / latency / token cost | 全部 < 阈值 → 升 25% |

| F.4 | 100% | 持续 | 全量监控 | 持续优化 |

**关键阈值**（暂定，按实际情况调）：

```
error_rate < 0.5%          (5% 阶段)
error_rate < 0.3%          (25%/50% 阶段)
error_rate < 0.1%          (100% 阶段)

p95 latency < 2x 当前基线
token cost < 预算 80%
```
