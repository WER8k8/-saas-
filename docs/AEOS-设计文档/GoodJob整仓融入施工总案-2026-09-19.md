## 3. 目标架构（两附属同构 · **Hermes 驱动** · **优化版**）

> **铁律**：TradeAI / GoodJob **不是**「打开附属 App 自己干活」；任务面 **= 爱马仕 Hermes 编排驱动**。  
> **优化铁律**：**双平面**（交互=UJ 同步 API；任务=Hermes）；**DSH 非每单必经**（默认 L1 直通）。

### 3.1 双平面

| 平面 | 适用 | 路径 | 禁止 |
|------|------|------|------|
| 交互平面 | 列表/详情/改字段/看会话 | 优丁 API 同步 + UJ RBAC | 强制 DSH/完整 DAG |
| 任务平面 | 多步拓客、外发、PI/CI/PL、跨系统 | Hermes（**默认 L1 模板**） | 附属自主主控调度 |

```text
交互：优丁 UI ──同步──► FastAPI :8001（PG 唯一真相）
任务：一键业务 ──► 爱马仕 Hermes
                   ├─ 默认 L1_template（不经 DSH）
                   ├─ 可选 DSH 拆图（模糊意图）→ 失败降级 L1
                   ▼
         并列执行器：TradeAI⑤ · GoodJob⑥ · DeerFlow④ · …
                   ▼
         优丁 PG + 证据 + 经验反哺
```

**位置法定**：人 →（可选 DSH①）→ 爱马仕② → **并列插件 ⑤⑥**（不在 DSH/Hermes 内部）。  
**SYSTEM-LOCK-02** = 能力域逻辑锁，≠ 必须 8 套独立登录/库/UI。

### 3.2 黄金路径（验收以路径为准，不单看串联率）

| ID | 路径 | 要求 |
|----|------|------|
| **GP-A** | 履约 PI（GoodJob）**P0 优先** | 优丁发起 → Hermes L1 `_fulfillment_graph` → 不打开附属台；节点可见；PG 有行或诚实 failed |
| **GP-B** | 拓客触达（TradeAI）P1 | 优丁发起 → Hermes 社媒/拓客图 → 无 Key 不假 sent |

| 维度 | 错误模式（禁止） | 正确模式 |
|------|------------------|----------|
| 任务面发起 | 附属管理台自己点 | 优丁 → **Hermes**（默认 L1） |
| 交互 CRUD | 进 DAG/DSH | **UJ API 同步** |
| 调度主权 | 附属 scheduler | Hermes/UJ 任务包 |
| 数据真相 | 附属库当 master | **仅优丁 PG** |
| 失败 | 假成功 | 诚实 failed/degraded + 证据 |

**iframe annex** = 仅诊断/过渡，非主工作模式。
