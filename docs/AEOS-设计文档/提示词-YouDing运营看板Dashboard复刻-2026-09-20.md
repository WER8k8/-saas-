# 提示词 · 实现 YouDing Materials 运营看板（Dashboard）

> 用途：直接复制给代码助手（Cursor / Claude Code / CodeBuddy / Trae 等）使用。
> 事实来源：设计截图（暖白底 + 薄荷绿的轻量卡片式 SaaS 看板）。
> 本提示词已修正截图中的占位文案问题，见 §3.3。

---

## 0. 角色与主要目标

你是资深前端工程师。请按下方规格，实现 **YouDing Materials 运营看板首页（Dashboard）**。

**三个主要目标**（按优先级）：

1. **视觉还原**：还原这套「暖白底 + 薄荷绿主色」的轻量卡片式看板气质——大留白、浅描边、极轻阴影、圆角卡片、克制用色。
2. **语义真实**：每个区块、每个字段都承载**真实业务含义**。截图中的标签多数是占位假文案（含拼写错误与重复），**禁止照抄**，必须按下表替换为语义化文案。
3. **工程可用**：组件化拆分、类型完整、可接真实数据、响应式适配 1440 → 375、无障碍达 WCAG AA、首屏有加载/空/错三态。

## 1. 覆盖范围（全部实现，不得删减或"简化省略"）

### 1.1 顶部应用栏（AppBar）
- 左：品牌 Logo（薄荷绿线性图标）+ 产品名 `YouDing Materials`
- 左中：状态徽标 `● Live Domain` + 下拉箭头 —— 表示当前站点域名已上线，点击可切换域名
- 右：帮助入口（`?`）、通知铃铛（**带未读红点**）、用户头像（圆形，首字母缩写，浅绿底）
- 交互：铃铛点击展开通知面板；头像点击展开菜单（退出登录等）；徽标下拉切换域名

### 1.2 左侧导航栏（Sidebar）
- 纵向图标 + 文字标签导航，首项为**当前选中态**（浅绿圆角底 + 主色图标与文字）
- 导航项（按截图顺序）：概览 / 内容 / 文件 / 设置
- 底部独立分组：帮助、退出登录
- 交互：选中态跟随路由；窄屏折叠

### 1.3 页面标题区
- 左：页面主标题 `Dashboard`
- 右：`Settings` 下拉按钮（白底描边）+ `Update Dashboard` 主按钮（薄荷绿实心）
- 交互：`Update Dashboard` 触发刷新数据，刷新中禁用并显示 loading；`Settings` 下拉含刷新频率、时间范围、卡片显隐

### 1.4 指标卡行（6 张，等宽一行）
每张卡：上方标签（小字、次级色）+ 下方大号数值（粗体）。
截图顺序与占位文案对应的**真实语义**见 §3.3 对照表。要求：
- 数值支持前缀（`$`）与单位（`K` / 条 / 人 / %），**不要硬编码字符串**，由数据层给出 `{ label, value, prefix, unit, trend }`
- 支持环比趋势（涨红跌绿，中国习惯）—— 若数据缺失则隐藏趋势位，不留空占位符

### 1.5 「待处理事项」区块（Action Required）
- 头部：标题 + 副标题（`Operational pipeline`）
- 右上：动作按钮（**不得与标题同名**，见 §3.3）
- 主体：**三段式横向流水线**，三个步骤卡，卡与卡之间用**细线/箭头连接**表达"流程推进"关系
- 每个步骤卡：步骤名（小标题）+ 状态描述（次级色）+ **金额/数值（大号，主色强调）** + 底部汇总说明
- 语义：这是运营待办流水线——从「触达」→「消耗」→「店铺成本」的推进视图
- 要求：连接线用内联 SVG 绘制；窄屏转为纵向堆叠，连接线随之改为竖向

### 1.6 「店铺与域名 SEO」区块（Storefront & Domain SEO）
- 头部：标题 + 副标题
- 右上：类型徽标（如 `Line chart`）
- 主体：**面积折线图**
  - Y 轴：0 / 50 / 100 / 150 / 200，5 条水平参考线
  - X 轴：1—8 月，**必须连续 12 个月刻度或完整 8 个月，禁止跳月**（截图中漏了 `Mar`，属缺陷，不要复刻）
  - 数据点带圆点标记 + 悬停 tooltip（日期 + 数值）
  - 折线用主色，面积填充为主色低透明度渐变（自上而下淡出）
- 无障碍：图表必须提供 `aria-label` 概述 + 可展开的**数据表格替代**（供读屏使用）

### 1.7 「海外买家询盘」区块（Inbound Buyer Inquiries）
- 头部：标题 + 右上徽标
- 副标题：`Country Buyer Inquiries`
- 国家筛选 chip 组：`USA` / `UAE` / `Germany`
  - 支持选中态（当前选中项为浅绿底 + 主色文字 + 主色描边）
  - 国旗图标**用内联 SVG 或 CSS 绘制，不要用 emoji 国旗**（跨平台渲染不一致）
- 下方两个下拉：`Country`、`Team country`
- 语义：按买家国家维度筛选询盘，并叠加"我方团队归属国"做对照

### 1.8 「多渠道状态」区块（Multi-platform Channel Status）
- 头部：标题 + 右上徽标
- 副标题：`Multi-platform channel status`
- 列表行结构：**渠道图标** | **渠道名 + 账号标识** | **数值（右对齐，大号）** | **状态徽标** | **右箭头**
- 状态徽标为浅绿 pill（`● 正常`），另需支持异常态（黄色）、断连态（红色）
- 交互：点击整行跳转该渠道详情；行悬停有底色反馈
- 渠道名必须用**真实渠道名**（见 §3.3，截图中的名称是错拼）

## 2. 关键约束

### 2.1 技术栈
- **Vue 3 + TypeScript + Ant Design Vue**（按目标仓库既有栈；若仓库是其它框架，**保持组件命名、目录结构、Props 契约不变，仅替换实现层**）
- 组件粒度：**每个区块一个独立组件**，不要写成一个巨型文件
- 数据层：所有区块数据经**统一 API 客户端**获取，禁止在组件里写死数字
- 类型：每个组件的 Props 与数据结构必须有显式 `interface` / `type` 定义
- 零外链：**不引任何 CDN / 外部字体 / 新增图表库**；图标用内联 SVG；图表优先用内联 SVG 手写或仓库已有图表库

### 2.2 视觉 Token（以截图为基准；若与仓库既有令牌冲突，**以仓库令牌为准**）

| 用途 | 值 |
|------|-----|
| 页面底 | `#EDF5F1`（暖白偏薄荷，**不要纯白**） |
| 卡片底 | `#FFFFFF` |
| 卡片描边 | `#E3EFEA`，1px |
| 主色（按钮 / 折线 / 强调） | `#4a9b8c` |
| 主色悬停 | `#3F8779` |
| 浅色强调底（徽标 / 选中态） | `#DFF3EA` |
| 深色文字 / 数值 | `#1E3330` |
| 次级文字（标签 / 副标题） | `#6B7F7A` |
| 分隔线 | `#E3EFEA` |
| 危险 / 未读点 | `#E8776F` |

- 圆角：卡片 `16px`、按钮 `10px`、徽标（pill）`999px`
- 阴影：**极轻**，`0 1px 2px rgba(31,74,66,.06)`；卡片主要靠 1px 描边区分层次，不靠大阴影
- 字号阶梯：`12 / 13 / 14(正文) / 16 / 20(区块标题) / 24 / 32(页面主标题 / 大数值)`
- 字重：仅用 **400 / 500**（数值与标题用 500，不要 700）
- 间距梯度：`4 / 8 / 12 / 16 / 24 / 32 / 48`
- 字体栈（系统字体，零外链）：`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "PingFang SC", "Microsoft YaHei", sans-serif`

### 2.3 ★ 文案规范：截图中的占位文案必须替换

**截图里的标签大多是 AI 生成占位文案，含拼写错误与语义重复。代码助手极易照抄进生产代码——这是本次最需要避免的错误。**

| 截图文案 | 问题 | 替换为 |
|---------|------|--------|
| `Total metrics`（**出现两次**） | 语义重复，两张卡同名 | 第 1 张 → `本月营收`；第 6 张 → `平均客单价` |
| `Custom service` | 语义模糊 | `定制服务收入` |
| `Domain reamons` | **拼写错误**（疑为 revenues） | `域名服务收入` |
| `Metric uported` | **拼写错误**（疑为 reported） | `已上报指标数` |
| `Earnance donation` | **拼写错误 + 语义不明** | `平台补贴收入` |
| `Action Required` 按钮 | **按钮文案与区块标题完全相同** | `立即处理` / `查看全部待办` |
| `Consanmation` | **拼写错误**（疑为 Consumption） | `资源消耗` |
| `Storeen cleaned` | **拼写错误**（疑为 Storefront） | `已清理店铺数` |
| `Subtitle: 56` | **占位符残留**，不是业务文案 | `本月新增 56 项` |
| `Total Impress` | **截断**（应为 Impressions） | `总曝光量` |
| `Ebadges` | **拼写错误**（疑为 Badges） | 徽标内改放真实维度名，如 `按国家` |
| `Ginameon` | **拼写错误**（疑为 Gemini / 渠道名） | 填**真实渠道名** |
| `Vinnam` | **拼写错误**（疑为 Vietnam） | `越南站` 或真实渠道名 |
| `Storefront rent` / `Communication` | 作为"流水线步骤名"语义尚可，但与副标题 `Operational pipeline` 不成体系 | 统一为流水线语义：`触达` → `消耗` → `店铺成本` |

**替换原则**：
- 一切文案必须**语义化、可理解**，禁止无意义英文缩写（如 `reamons`、`uported`）
- 同名标签禁止出现两次
- 按钮文案不得与所在区块标题相同
- 若某字段真实含义不确定，**保留占位并加 `TODO` 注释**，不要编造一个看起来对的假文案

### 2.4 响应式（必须实现）
| 断点 | 布局 |
|------|------|
| ≥1440 | 指标卡 6 列；下方区块 2 列 ×2 行；左侧栏常驻 |
| 1024–1439 | 指标卡 3 列 ×2 行；区块仍 2 列 |
| 768–1023 | 指标卡 2 列；区块 1 列堆叠 |
| <768 | 全单列；左侧栏收起为汉堡菜单或底部 Tab；按钮最小点击区 **≥44×44px**；输入框字号 **≥16px**（防 iOS 自动缩放）；适配 `env(safe-area-inset-bottom)` |

### 2.5 状态与容错（每个区块都要有）
- **加载中**：骨架屏（不要转圈，避免布局跳变）
- **空数据**：说明文字 + 下一步动作（如"暂无线索，去发布内容获取询盘"）
- **错误**：错误提示 + 重试按钮
- **无权限**：明确的权限提示（若该看板有角色区分）
- 数值格式化：金额千分位 + 单位；百分比保留 1 位；大数用 `K` / `M` 缩写并保证与原始值一致

### 2.6 无障碍（WCAG AA）
- 正文对比度 **≥4.5:1**；大号数值 ≥3:1
- 全站键盘可达，焦点环清晰可见
- 图表与纯图标按钮必须有 `aria-label`
- 状态不能只靠颜色区分，须同时有图标或文字（色盲友好）

### 2.7 禁止项
- ❌ 照抄截图中的错拼 / 重复 / 占位文案
- ❌ 引入外部 CDN、外部字体、新图表库
- ❌ 用 emoji 当图标或国旗
- ❌ 组件里写死数据
- ❌ 用纯白当页面底（会显得发脏）
- ❌ 大阴影重投影（破坏轻量气质）

## 3. 期望的输出形式

### 3.1 文件结构
```
src/views/dashboard/
├── index.vue                      # 页面容器：编排各区块 + 统一数据获取
└── components/
    ├── AppBar.vue                 # 顶部应用栏
    ├── SideNav.vue                # 左侧导航
    ├── PageHeader.vue             # 标题 + Settings / Update 按钮
    ├── MetricCardRow.vue          # 指标卡行（含 MetricCard.vue 子组件）
    ├── ActionRequiredPanel.vue    # 待处理流水线（含 PipelineStep.vue）
    ├── StorefrontSeoPanel.vue     # 面积折线图
    ├── InboundInquiriesPanel.vue  # 国家筛选 + 下拉
    └── ChannelStatusPanel.vue     # 多渠道状态列表
```
另需：
- `types/dashboard.ts` —— 全部数据结构与 Props 类型定义
- `mocks/dashboard.ts` —— **合理量级的示例数据**（非空、非全零、含 1 条异常态以体现状态设计）
- 若仓库有设计令牌文件，**复用并扩展，不要新起一套**

### 3.2 每个组件的交付要求
1. `<script setup lang="ts">` + 显式类型
2. Props 为纯数据输入（便于单独测试与 Storybook 化）
3. 样式用 `<style scoped>`，颜色**引用 Token 变量**而非硬编码十六进制
4. 关键交互补一行注释说明意图

### 3.3 交付后必须自检并回报
- [ ] 区块数量与 §1 一致（**8 个区块一个不少**）
- [ ] §2.3 对照表中的每一条错拼/占位文案**均已替换**，可逐一列出替换结果
- [ ] 四个断点均无横向滚动、无文字溢出
- [ ] 6 张指标卡 + 折线图 + 列表，加载态 / 空态 / 错误态三态均可触发验证
- [ ] 不新增任何外部依赖
- [ ] 键盘 Tab 走查一遍，焦点可见

## 4. 追加说明（若在既有项目中落地）

- 该看板对应运营看板的**首屏决策页**，应遵循项目既有令牌锁：主色锁定 `#4a9b8c`，**不要改成其它主色**；不引入暗色主题分支。
- 若项目已有《马卡龙薄荷玻璃态配色方案》，可直接引用其 Token：
  - 主色 `--color-primary: #4a9b8c`、悬停 `#3F8779`
  - **实心按钮若含正文级白字，用 `--color-primary-strong: #367469`**（白字对比度 5.44 达 AA；直接用 `#4a9b8c` 仅 3.30，只够大字）
  - 正文中的品牌色链接用 `#2F6A5F`，不要直接用 `#4a9b8c`（仅 3.17，不合格）
  - 页面底用 `#F7FBFA` 或本提示词的 `#EDF5F1`，均不用纯白
- 若需玻璃态质感，可在卡片上加极轻的 `backdrop-filter: blur(20px)`，但**页面底必须有色彩底衬**，否则玻璃退化为白卡片。
